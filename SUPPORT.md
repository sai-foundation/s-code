# Support

Opencoding Community is currently in private release-candidate development.
There is no production support commitment or public stable release.

For invited testers:

- use [GitHub Issues](https://github.com/shilongliu-iteria/opencoding-community/issues)
  for reproducible bugs and feature requests;
- include the source commit, operating system, architecture, expected behavior
  and minimal reproduction;
- remove tokens, source code, workspace paths and personal or customer data;
- use the private process in [`SECURITY.md`](SECURITY.md) for vulnerabilities.

Questions, deployment consulting, response-time guarantees and support for
private Enterprise components are outside the Community support commitment.
